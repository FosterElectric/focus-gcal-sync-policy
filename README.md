# プライバシーポリシー（FoCUS to Google Calendar 連携拡張機能）

本拡張機能は、フォスター電機株式会社の社内利用限定のツールです。

## 取得する情報

- FoCUS上の予定情報（タイトル、日時、参加者、場所等）
- Chromeにログイン中の社内Googleアカウントのメールアドレス

## 利用目的

上記情報は、FoCUSの予定をGoogleカレンダーへ登録する目的にのみ使用します。
取得した情報を第三者へ提供することはありません。

## データの保存

本拡張機能は、認証情報（ID・パスワード等）を保存しません。
連携された予定データはGoogleカレンダーおよびFoCUS上にのみ保存されます。
